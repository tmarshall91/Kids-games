# Go Fish

A classic card matching game where players try to collect pairs (four of a kind) by asking their opponent for cards.

## How to Play

1. You and the computer start with 7 cards each
2. Tap any card in your hand to ask the computer for that rank
3. If the computer has cards of that rank, you get them all!
4. If not, "Go Fish!" - draw a card from the deck
5. Collect four cards of the same rank to make a pair
6. The player with the most pairs when all cards are gone wins!

## Features

- Mobile-friendly touch controls
- Automatic pair detection
- Turn-based gameplay
- Visual feedback for all actions
- Score tracking

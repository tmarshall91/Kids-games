# Tic-Tac-Toe

The classic strategy game where you try to get three in a row before the computer does!

## How to Play

1. You are X, the computer is O
2. Tap any empty cell to place your mark
3. Try to get three of your marks in a row (horizontal, vertical, or diagonal)
4. Block the computer from getting three in a row
5. First to three in a row wins!

## Features

- Play against a smart computer opponent
- Instant visual feedback
- Winning combinations highlighted
- Mobile-friendly touch controls
- Clean, colorful interface

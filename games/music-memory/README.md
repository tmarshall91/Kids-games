# Music Memory 🎵

A musical twist on the classic memory game! Watch and listen to the sequence, then repeat it. Each level adds one more note!

## How to Play

1. Tap **Start Game** to begin
2. **Watch and listen** as the colored buttons light up and play notes
3. **Repeat the sequence** by tapping the buttons in the same order
4. Each level adds **one more note** to the sequence
5. Keep going as long as you can remember!

## Controls

- **Tap/Click**: Press the colored buttons to repeat the sequence
- **Touch-friendly**: Optimized for mobile devices

## Objective

- Remember and repeat musical sequences
- Each correct sequence increases your level
- Score increases with each level (level × 10 points)
- Try to reach the highest level possible!

## Features

- **6 Colored Buttons**: Each with a unique musical note
- **Progressive Difficulty**: Sequences get longer each round
- **Audio-Visual Feedback**: Buttons light up and play notes
- **Score System**: Earn more points at higher levels
- **Level Tracking**: See how far you can go
- **Mobile-Optimized**: Touch-friendly interface

## Musical Notes

Each colored button plays a different musical note:

1. **Red** - C4 (261.63 Hz)
2. **Yellow** - D4 (293.66 Hz)
3. **Green** - E4 (329.63 Hz)
4. **Blue** - G4 (392.00 Hz)
5. **Purple** - A4 (440.00 Hz)
6. **Orange** - C5 (523.25 Hz)

## Game Flow

1. **Watch Phase**: The game plays the sequence
2. **Your Turn**: Repeat the sequence by tapping buttons
3. **Success**: Correct sequence moves you to the next level
4. **Mistake**: Wrong note ends the game

## Tips

- **Focus on the patterns** - both visual and audio
- **Say the colors out loud** as you play them
- **Take your time** - no rush on your turn
- **Listen carefully** to the musical notes
- **Practice makes perfect** - the more you play, the better you'll get!

## Strategy

- Watch AND listen - use both senses
- Chunk the sequence into smaller groups
- Repeat the sequence mentally before playing
- Stay calm and focused
- Start over if you need more practice

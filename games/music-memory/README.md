# Music Memory

A musical memory game where players must remember and repeat increasingly longer sequences of musical notes. Similar to Simon Says but with musical notes!

## How to Play

1. Tap "Start Game" to begin
2. Watch and listen as the game plays a sequence of notes
3. When it's your turn, repeat the sequence by tapping the colored pads in the same order
4. Each level adds one more note to the sequence
5. The game ends if you tap the wrong note

## Game Features

- **Musical Notes**: Four notes (Do, Re, Mi, Fa) with distinct sounds and colors
- **Progressive Difficulty**: Sequence gets longer with each level
- **Visual and Audio Cues**: Each pad lights up and plays its note
- **Best Score Tracking**: Keeps track of your highest level
- **Memory Training**: Great exercise for auditory and visual memory

## The Four Notes

- **Red Pad (Do)**: C note - 261.63 Hz
- **Blue Pad (Re)**: D note - 293.66 Hz
- **Green Pad (Mi)**: E note - 329.63 Hz
- **Yellow Pad (Fa)**: F note - 349.23 Hz

## Game Mechanics

- Level 1 starts with 1 note
- Each successful round adds 1 more note to the sequence
- You must repeat the entire sequence from the beginning
- One wrong note ends the game
- Best score is saved locally

## Technical Details

- **Technologies**: HTML5, CSS3, Vanilla JavaScript, Web Audio API
- **Mobile Optimized**: Touch-friendly responsive design
- **Browser Requirements**: Modern browsers with Web Audio API support

## Learning Benefits

- **Memory Development**: Strengthens short-term memory
- **Pattern Recognition**: Learn to recognize and remember patterns
- **Musical Ear Training**: Develop ability to distinguish musical notes
- **Concentration**: Improves focus and attention span
- **Sequential Thinking**: Practice remembering order and sequences

## Tips for High Scores

- Focus on both the visual and audio cues
- Try to sing the sequence in your head
- Use patterns and associations to remember longer sequences
- Take your time when repeating - accuracy matters more than speed
- Practice regularly to improve your memory capacity

## Difficulty Progression

- Levels 1-3: Easy (3-5 notes)
- Levels 4-7: Medium (4-7 notes)
- Levels 8-12: Hard (8-12 notes)
- Levels 13+: Expert (13+ notes)

# Memory Cards

Match pairs of cards by remembering their locations. Choose from different fun themes!

## How to Play

1. Choose a theme (Animals, Fruits, Emojis, or Numbers)
2. Tap any card to flip it over
3. Tap another card to find its match
4. If they match, they stay flipped
5. If not, they flip back - remember where they are!
6. Match all 8 pairs to win

## Features

- 4 different themes to choose from
- Move counter
- Timer to track your speed
- Smooth animations
- Mobile-friendly touch controls
- Perfect for memory training

## Technical Details

- Pure HTML5, CSS3, and Vanilla JavaScript
- 16 cards (8 pairs) per game
- Responsive grid layout
- Touch and mouse event support
- No external dependencies

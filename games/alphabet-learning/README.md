# Alphabet Learning

An interactive alphabet learning game where kids can tap letters to learn their sounds and practice letter recognition.

## How to Play

1. Tap "Let's Learn!" to start
2. Tap any letter to hear/see its phonetic sound
3. Learn all 26 letters at your own pace
4. Once you've learned some letters, try "Quiz Mode" to test your knowledge
5. In quiz mode, find the letter that matches the given sound

## Features

- Complete A-Z alphabet grid
- Phonetic sound display for each letter
- Visual feedback when tapping letters
- Progress tracking (letters learned)
- Practice mode for free exploration
- Quiz mode to test knowledge
- Colorful, kid-friendly interface
- Letters turn green when learned

## Educational Value

This game helps children:
- Learn letter recognition (A-Z)
- Associate letters with their sounds
- Practice phonics fundamentals
- Build alphabet knowledge
- Develop visual letter discrimination

- Pure HTML5, CSS3, and vanilla JavaScript

- Responsive grid layout

## Modes

### Practice Mode (Default)
- Tap any letter to learn its sound
- No pressure, explore freely
- Letters are marked as "learned" when tapped
- Build familiarity with the alphabet

### Quiz Mode
- Tests recognition of learned letters
- Shows a phonetic sound, find the matching letter
- Multiple choice format (6 options)
- Immediate feedback on answers

## Controls

- **Touch/Click**: Tap letter cards to hear their sounds
- **Practice Mode Button**: Return to free exploration
- **Quiz Mode Button**: Test your knowledge

## Difficulty

- Beginner-friendly
- Self-paced learning
- Quiz only uses letters you've already learned
- No time pressure

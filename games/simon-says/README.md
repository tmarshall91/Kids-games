# Simon Says

A classic memory sequence game where players must watch and repeat increasingly long patterns of colors and sounds.

## How to Play

1. **Watch Carefully**: Simon will show you a sequence of colored buttons lighting up
2. **Remember the Pattern**: Each button has a unique color and sound
3. **Repeat the Sequence**: Tap the buttons in the same order Simon showed you
4. **Level Up**: Each round adds one more step to the sequence
5. **Keep Going**: See how far you can go without making a mistake!

## Game Controls

- **Tap the colored buttons** in the correct order to match Simon's pattern
- **Start Game**: Begin a new game
- **New Game**: Restart during gameplay

## Features

- 4 colorful buttons (Green, Red, Yellow, Blue)
- Unique musical tone for each button
- Progressive difficulty - sequence gets longer each round
- Score increases with level (higher levels = more points)
- Visual and audio feedback for every interaction
- Mobile-optimized touch controls
- Game Over screen showing your final level and score

## Scoring

- Each successful round awards points based on the level
- Formula: Level × 10 points
- Example: Level 5 = 50 points, Level 10 = 100 points

## Tips

- Focus on both the visual pattern AND the sounds
- The sounds can help you remember the sequence
- Start with small chunks - remember 2-3 at a time, then link them together
- Don't rush - take your time to recall the pattern
- Practice makes perfect!

- Each round adds one random button to the sequence
- Sequences can get very long - the record is well over 20!
- Wrong button press immediately ends the game
- No time limit - play at your own pace

# Stack the Blocks

A timing-based game where you stack moving blocks to build the tallest tower possible!

## How to Play

1. Tap "Start Stacking" to begin
2. Watch the block move left and right
3. Tap to drop the block onto the tower
4. Stack blocks as accurately as possible
5. **Perfect drops** (centered perfectly) keep the block at full width
6. **Imperfect drops** cut off the overhanging part
7. Game ends when you miss completely or block becomes too small
8. Build the highest tower you can!

## Features

- Simple one-tap timing mechanic
- Perfect drop bonus system
- Colorful blocks
- Progressive difficulty (speed increases)
- High score tracking
- Satisfying stacking gameplay
- Mobile-optimized controls

- **Technologies**: HTML5 Canvas, CSS3, Vanilla JavaScript

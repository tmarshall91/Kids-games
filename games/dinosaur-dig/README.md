# 🦴 Dinosaur Dig

Become a paleontologist and excavate complete dinosaur fossils from ancient dig sites!

## How to Play

1. **Tap to Dig**: Click or tap any dirt tile to excavate
2. **Find Fossils**: Uncover hidden dinosaur bone pieces
3. **Collect Sets**: Find all 3 pieces of each dinosaur
4. **Complete Discoveries**: Get bonus points for complete fossils
5. **New Sites**: Start a new dig site to find more fossils

## Dinosaurs to Discover

Each dinosaur requires 3 fossil pieces to complete:

- **🦕 Brachiosaurus** - Long-necked gentle giant
- **🦖 T-Rex** - Fearsome predator
- **🦴 Triceratops** - Three-horned herbivore
- **🐊 Pterodactyl** - Flying reptile

## Features

- **6x6 Dig Grid**: 36 tiles to excavate per site
- **12 Hidden Fossils**: Randomly distributed each game
- **4 Dinosaur Types**: Collect them all!
- **Progress Tracking**: See how many pieces of each dino you've found
- **Completion Bonus**: +100 points for completing a dinosaur
- **Unlimited Sites**: Keep digging at new locations

## Game Mechanics

- **Grid Size**: 6×6 = 36 tiles per site
- **Fossils Per Site**: 12 hidden fossils
- **Distribution**: Evenly split among 4 dinosaur types
- **Random Placement**: Fossils randomly positioned each time
- **Persistent Progress**: Score carries over to new sites

## Scoring System

- **Fossil Found**: +10 points per piece
- **Complete Dinosaur**: +100 bonus points
- **Total possible per site**: 120 base + up to 400 bonus = 520 points

## Progress Display

The discovered fossils area shows:
- Each dinosaur you've found pieces of
- Progress counter (e.g., "2/3" pieces found)
- Complete dinosaurs highlighted in green

## Strategy Tips

- Systematically dig in patterns to cover all areas
- Keep track of which dinosaurs you're close to completing
- Complete dinosaurs for big bonus points
- Start new sites to find more fossils and increase score

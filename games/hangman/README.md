# Hangman

Classic word-guessing game! Guess the word letter by letter before the hangman is complete.

## How to Play

1. Tap "Start Game" to begin
2. A random word will be chosen (shown as blank spaces)
3. Tap letters on the keyboard to guess
4. If the letter is in the word, it will appear
5. If wrong, a body part is added to the hangman
6. You have 6 wrong guesses before game over
7. Guess all letters correctly to win!

## Features

- Touch-optimized keyboard
- Visual hangman drawing
- Score tracking across rounds
- Kid-friendly animal words
- Color-coded feedback (green=correct, red=wrong)
- Responsive design for all devices

## Technical Details

- Pure HTML5, CSS3, and Vanilla JavaScript
- Mobile-first design
- Touch and mouse support
- SVG-based hangman illustration
- No external dependencies
- Works offline

## Controls

- **Touch/Click**: Tap letter keys to guess
- **New Word**: Start a new round with a different word

## Word Categories

Current category: Animals (elephant, giraffe, monkey, tiger, rabbit, dolphin, penguin, lion, zebra, kangaroo, butterfly, squirrel, turtle, flamingo, panda)

## Scoring

- Win a round: +10 points
- Score accumulates across rounds
- Try to get the highest score possible!

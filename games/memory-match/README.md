# Memory Match (Concentration)

A classic memory card game where players flip cards to find matching pairs of symbols.

## How to Play

1. Choose your difficulty level (6, 8, or 12 pairs)
2. Cards are shuffled and placed face down
3. Tap a card to flip it and reveal the symbol
4. Tap another card to find its match
5. If the symbols match, the cards stay flipped
6. If they don't match, they flip back over
7. Find all pairs to win!

## Controls

- **Tap/Click**: Flip a card
- **Reset Game**: Shuffle and start over with the same difficulty
- **New Game**: Return to difficulty selection

## Features

- Three difficulty levels (6, 8, or 12 pairs)
- Colorful emoji symbols
- Move counter
- Timer to track completion time
- Matched pairs counter
- Smooth card flip animations
- Mobile-friendly touch controls
- Responsive design

## Game Tips

- Try to remember where symbols are located
- Start by flipping cards in a systematic pattern
- The fewer moves, the better your memory!

## Technical Details

- Pure HTML5, CSS3, and Vanilla JavaScript
- No external dependencies
- Mobile-optimized with touch support
- 3D flip animations using CSS transforms

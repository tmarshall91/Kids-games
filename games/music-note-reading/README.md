# Music Note Reading 🎼

Learn to read musical notes! Practice recognizing notes on the staff and improve your music reading skills.

## How to Play

1. Tap **Start Learning** to begin
2. **Look at the note** on the music staff
3. **Tap the correct note name** (A, B, C, D, E, F, G)
4. Get feedback and keep practicing!
5. Level up as you improve!

## Controls

- **Tap/Click**: Select note names

## Features

- **7 Musical Notes**: A through G
- **Visual Staff**: See notes on the musical staff
- **Immediate Feedback**: Learn from mistakes
- **Progressive Difficulty**: Start easy, get challenging
- **Score Tracking**: Track your progress

# Music Note Reading

Learn to read music by identifying notes on the musical staff! Perfect for beginners learning music notation.

## How to Play

1. Tap "Start Learning" to begin
2. A note will appear on the musical staff and play its sound
3. Identify which note it is (C, D, E, F, G, A, or B)
4. Tap the correct letter button
5. Get 10 points for each correct answer
6. Complete 20 rounds to finish the game

## Musical Staff

The game shows a treble clef staff with 5 lines. Notes can appear on:
- **Lines** (from bottom to top): E, G, B, D, F
- **Spaces** (from bottom to top): F, A, C, E

Notes shown:
- C (middle C) - Below the staff
- D - Below line 1
- E - On line 1
- F - Space 1
- G - Line 2
- A - Space 2
- B - Line 3

## Features

- **Visual Staff**: Standard musical staff with proper note positions
- **Audio Feedback**: Hear each note as it appears
- **Immediate Feedback**: Know right away if you're correct
- **Score System**: 10 points per correct answer
- **Streak Counter**: Track consecutive correct answers
- **20 Rounds**: Complete game session

## Game Mechanics

- Random note appears on staff
- Note plays its sound automatically
- Choose from 7 possible notes (C, D, E, F, G, A, B)
- Correct answers increase streak and score
- Wrong answers reset streak
- Game ends after 20 notes

## Learning Tips

**Remember the Lines (E-G-B-D-F):**
- "Every Good Boy Does Fine"
- "Every Good Boy Deserves Fudge"

**Remember the Spaces (F-A-C-E):**
- Just spell "FACE"!

**Practice Strategies:**
- Start by learning line notes, then space notes
- Use the sound to help you
- Practice regularly to improve
- Try to beat your streak record

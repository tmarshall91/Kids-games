# Speed Matching

A fast-paced card matching game where all cards are visible from the start! Race against time to match pairs quickly and build combo chains for maximum points.

## How to Play

1. **Choose Your Settings**
   - Select a difficulty level (Easy, Medium, or Hard)
   - Pick your favorite theme (Animals, Fruits, Emojis, or Sports)
   - Click "START GAME" to begin

2. **Match the Pairs**
   - All cards are face-up and visible
   - Tap/click on one card, then tap/click its matching pair
   - Match all pairs before time runs out!

3. **Score Big**
   - Base points: 100 per match
   - Speed bonus: +50 points for matches under 2 seconds
   - Combo multiplier: Chain matches together for exponential points (1.5x per combo)
   - Time bonus: +10 points per second remaining when you win

4. **Controls**
   - **Pause**: Press the Pause button to take a break
   - **Quit**: End the current game
   - **Back to Games**: Return to the main menu

## Features

### Difficulty Levels
- **Easy**: 60 seconds, 12 cards (6 pairs)
- **Medium**: 45 seconds, 16 cards (8 pairs)
- **Hard**: 30 seconds, 20 cards (10 pairs)

### Themes
- **Animals**: Cute animal emojis
- **Fruits**: Colorful fruit emojis
- **Emojis**: Fun smiley faces
- **Sports**: Various sport equipment

### Scoring System
- **Base Points**: 100 points per match
- **Speed Bonus**: Extra 50 points for quick matches (under 2 seconds)
- **Combo System**: Chain matches together for multiplied points
  - 2nd match in combo: 1.5x points
  - 3rd match in combo: 2.25x points
  - 4th match in combo: 3.375x points (and so on!)
- **Time Bonus**: When you win, earn 10 bonus points for each second remaining

### Visual Feedback
- Selected cards glow with golden highlight
- Matched cards turn green and fade
- Wrong selections shake briefly
- Timer turns red when under 10 seconds
- Combo counter appears when you build a chain

## Game Differences from Memory Cards

Unlike the Memory Cards game where cards start face-down:
- **All cards visible**: Cards are face-up from the start
- **Speed focus**: Race against a countdown timer
- **Combo system**: Chain matches for multiplier bonuses
- **Time pressure**: Limited time adds urgency
- **Speed rewards**: Faster matches earn more points

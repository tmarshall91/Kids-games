# Spray Paint Simulator 🎨

Create graffiti-style art with a realistic spray paint effect!

## How to Play

1. **Choose a Color**: Select from vibrant spray paint colors
2. **Pick Spray Size**: Small, medium, or large spray
3. **Paint**: Hold and drag to spray paint on the wall
4. **Create Art**: Make tags, murals, or abstract designs

## Features

- **6 Spray Colors**: Red, green, blue, yellow, pink, and white
- **3 Spray Sizes**: Different spray can nozzle sizes
- **Realistic Spray Effect**: Particle-based spray simulation
- **Dark Wall**: Authentic street art canvas
- **Variable Opacity**: Realistic paint buildup

## Technical Details

- Particle-based spray simulation
- Random distribution for realistic effect
- Variable opacity for paint layers
- Touch-optimized continuous spray

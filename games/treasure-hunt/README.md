# Treasure Hunt

An interactive adventure game where kids follow riddle clues to discover hidden treasure on a colorful map!

## How to Play

1. **Start the Adventure**: Tap the "Start Adventure" button to begin your treasure hunt
2. **Read the Clue**: Each riddle gives you a hint about where to go next
3. **Find the Location**: Look at the map and tap the location that matches the clue
4. **Progress Through**: Work your way through 7 locations following the clues
5. **Need Help?**: Tap the "Need a Hint?" button if you get stuck
6. **Find the Treasure**: Complete all clues to discover the hidden treasure!

## Game Features

- **7 Unique Locations**: Beach, Palm Tree, Cave, Waterfall, Mountain, Ancient Ruins, and Treasure
- **Kid-Friendly Riddles**: Each location has a fun riddle clue appropriate for children
- **Hint System**: Get helpful hints if you're stuck on a clue
- **Visual Progress**: See which locations you've already discovered
- **Timer**: Track how fast you can complete the treasure hunt
- **Mobile-Optimized**: Designed for touch-friendly gameplay on phones and tablets
- **Colorful Interface**: Bright, engaging design with emojis and animations

## Controls

- **Tap/Click** on map locations to select them
- **Tap "Need a Hint?"** button to reveal a helpful hint
- **Tap "New Adventure"** to restart the hunt at any time

## Game Mechanics

- Only the **current target location** can be tapped (shown with a glowing green border)
- Previously found locations are marked with a checkmark (✓)
- Locked locations show a lock icon (🔒)
- The current target shows a location pin (📍)
- Hints can only be used once per clue
- Your time and number of hints used are tracked

## Educational Value

This game helps children develop:
- **Reading Comprehension**: Understanding and interpreting riddle clues
- **Problem-Solving**: Figuring out which location matches each clue
- **Logical Thinking**: Following a sequence of clues to reach a goal
- **Visual Recognition**: Matching descriptions to visual representations
- **Memory**: Remembering which locations have been visited

## Technical Details

- **Technologies**: HTML5, CSS3, Vanilla JavaScript
- **Browser Compatibility**: Works on modern mobile and desktop browsers
- **Responsive Design**: Optimized for screens from 320px to 428px width
- **No External Dependencies**: All assets are self-contained
- **Offline-Capable**: Can be played without an internet connection

## Scoring

Your performance is measured by:
- **Time**: How quickly you complete the treasure hunt
- **Hints Used**: Fewer hints used means better performance
- **Completion**: Finding all 7 locations and the treasure

## Tips for Players

1. Read each clue carefully before selecting a location
2. Think about what each emoji represents
3. Use hints strategically if you're really stuck
4. Try to beat your best time on replay!
5. Challenge friends and family to compare times

# Fish Swimming Maze 🐠

Guide your fish through underwater mazes to reach the treasure star!

## How to Play

1. Tap **Start Swimming** to begin
2. Use the arrow buttons (⬆️ ⬇️ ⬅️ ➡️) to move your fish
3. Navigate around the purple coral walls
4. Reach the glowing star (⭐) to complete the level
5. Try to finish each level as quickly as possible!

## Features

- **Multiple levels** with increasing difficulty
- **Touch-friendly arrow controls** for easy navigation
- **Keyboard support** (Arrow keys or WASD)
- **Timer** to track your speed
- **Beautiful underwater theme** with decorations
- Progressive maze complexity
- Level completion celebration

## Game Mechanics

- Move one cell at a time using direction buttons
- Cannot pass through coral walls
- Each level has a unique maze layout
- Timer tracks how long you take
- Levels cycle with increasing patterns

## Controls

**Touch Controls:**
- Tap arrow buttons to move

**Keyboard Controls:**
- Arrow Keys or WASD to move
- Works on desktop browsers

# Piano Tiles 🎹

A classic piano tiles game where players tap falling black tiles to create music. Test your reflexes and rhythm!

## How to Play

1. Tap the **Start Game** button to begin
2. Tap the black tiles as they fall down the screen
3. **Don't miss any tiles** - they must be tapped before reaching the bottom
4. **Don't tap empty lanes** - this will end the game
5. The game speeds up as you score more points!

## Controls

- **Tap/Click**: Tap the black tiles in their lanes
- **Touch-friendly**: Optimized for mobile devices

## Objective

- Score as many points as possible by tapping tiles
- Each tile is worth 10 points
- The speed increases every 10 tiles
- Try to beat your high score!

## Features

- Progressive difficulty - speed increases over time
- Smooth animations and responsive controls
- Score tracking
- Speed multiplier display
- Mobile-optimized touch controls
- Visual feedback on tile taps

## Technical Details

- **Technologies**: HTML5, CSS3, Vanilla JavaScript
- **Browser Requirements**: Modern mobile and desktop browsers
- **Mobile-first**: Optimized for touch screens
- **Performance**: 60 FPS gameplay with requestAnimationFrame

## Game Mechanics

- **4 lanes**: Tiles fall down 4 piano lanes
- **Random generation**: Tiles appear randomly in different lanes
- **Speed progression**: Speed increases every 10 tiles
- **Instant feedback**: Visual feedback when tiles are tapped
- **Game Over**: Missing a tile or tapping an empty lane ends the game

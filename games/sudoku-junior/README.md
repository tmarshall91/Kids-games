# 🧩 Sudoku Junior

A kid-friendly Sudoku game with simplified 4×4 and 6×6 grids! Perfect for introducing logic puzzles to young minds.

## How to Play

1. **Choose Your Level**:
   - 🟢 **Easy**: 4×4 grid with numbers 1-4
   - 🟡 **Medium**: 6×6 grid with numbers 1-6

2. **Tap a cell** to select it
3. **Tap a number** from the pad below to fill it in
4. **Complete the puzzle** by filling all empty cells correctly!

## Controls

- **Tap/Click Cell**: Select a cell to fill
- **Tap/Click Number**: Place that number in the selected cell
- **✖ Button**: Clear a cell
- **💡 Hint**: Get help with one cell (limited hints)
- **✅ Check**: Verify your solution
- **🎮 New Game**: Start a new puzzle

## Sudoku Rules

Each puzzle must follow these simple rules:

1. **🔢 Rows**: Every row must contain each number exactly once
2. **📊 Columns**: Every column must contain each number exactly once
3. **🎯 Boxes**: Every box (outlined section) must contain each number exactly once

## Difficulty Levels

### Easy (4×4)
- Grid: 4 rows × 4 columns
- Numbers: 1, 2, 3, 4
- Boxes: 2×2 sections
- Perfect for beginners!

### Medium (6×6)
- Grid: 6 rows × 6 columns
- Numbers: 1, 2, 3, 4, 5, 6
- Boxes: 2×3 sections
- More challenging!

## Game Features

- Two difficulty levels (4×4 and 6×6)
- Auto-generated puzzles with unique solutions
- Visual feedback for correct/incorrect entries
- Hint system (3 hints available)
- Solution checker
- Timer to track your speed
- Mistake counter (3 mistakes allowed)
- Star rating system
- Touch-optimized for mobile

## Scoring & Rating

Your performance is rated by stars:

- **⭐ 1 Star**: Complete the puzzle
- **⭐⭐ 2 Stars**: Complete with 1 or fewer mistakes
- **⭐⭐⭐ 3 Stars**: Perfect! No mistakes and no hints used

## Visual Indicators

- **Blue cells**: Given numbers (cannot be changed)
- **Yellow cell**: Currently selected cell
- **Light blue cells**: Cells in the same row/column as selected
- **Green cells**: Correctly placed numbers
- **Red cells**: Incorrect numbers (with shake animation)

## Tips for Success

- Start with rows, columns, or boxes that have the most numbers filled
- Use the process of elimination
- Look for numbers that can only go in one place
- Check your work regularly
- Don't be afraid to use hints when stuck!

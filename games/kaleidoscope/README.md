# Kaleidoscope Creator 🔮

Create mesmerizing symmetrical patterns with rainbow colors!

## How to Play

1. **Choose Segments**: Select 4, 6, 8, 12, or 16 segments
2. **Draw Mode**: Drag to create symmetrical patterns
3. **Animate Mode**: Watch automatic pattern generation
4. **Watch Magic**: See your strokes mirrored across all segments

## Features

- **5 Segment Options**: From 4 to 16 symmetrical segments
- **Two Modes**:
  - 🖌️ Draw: Manual pattern creation
  - ✨ Animate: Automatic mesmerizing animations
- **Rainbow Colors**: Automatic color cycling
- **Mirror Effect**: Each segment has vertical mirroring
- **Circular Canvas**: True kaleidoscope appearance

## Technical Details

- Advanced canvas rotation and mirroring
- Real-time symmetrical rendering
- HSL color cycling
- Animation loop with requestAnimationFrame
- Multi-segment coordinate transformation

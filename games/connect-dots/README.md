# Connect the Dots

Connect numbered dots in sequence to reveal hidden pictures in this classic drawing game!

## How to Play

1. Click "Start Game" to begin
2. Click or tap on dot #1 to start
3. Continue clicking dots in numerical order
4. Watch as the picture is revealed
5. Complete all connections to see the final picture!

## Controls

- **Tap/Click**: Connect the next numbered dot
- **Clear & Restart**: Erase all connections and start over
- **New Picture**: Get a different picture to draw

## Features

- Multiple picture templates (stars, houses, hearts, etc.)
- Visual feedback for the next dot to click
- Progress tracker
- Connected dots turn green
- Next dot pulses orange
- Final picture revealed with color fill
- Touch-friendly for mobile
- Responsive canvas sizing

## Game Tips

- Follow the numbers in order from 1
- The next dot you need to click is highlighted in orange
- Take your time - there's no rush!
- Use "Clear & Restart" if you want to try again

## Technical Details

- Pure HTML5, CSS3, and Vanilla JavaScript
- HTML5 Canvas for drawing
- No external dependencies
- Touch and mouse support
- Mobile-optimized with responsive sizing
- Smooth line rendering

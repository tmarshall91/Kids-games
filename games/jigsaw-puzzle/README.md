# Jigsaw Puzzle

Arrange colorful puzzle pieces to complete the picture in this classic jigsaw puzzle game!

## How to Play

1. Choose your difficulty level (2×2, 3×3, or 4×4 grid)
2. Drag and drop puzzle pieces from the bottom to the correct positions on the board
3. Pieces will only snap into place if positioned correctly
4. Complete the entire puzzle to win!

## Controls

- **Drag & Drop**: Move pieces to the board (desktop)
- **Touch & Drag**: Move pieces to the board (mobile)
- **Shuffle Pieces**: Randomize the order of remaining pieces
- **New Game**: Return to difficulty selection

## Features

- Three difficulty levels (4, 9, or 16 pieces)
- Colorful gradient pieces
- Drag and drop mechanics
- Touch-friendly for mobile devices
- Only correct placements are accepted
- Timer to track completion
- Progress counter
- Responsive design

## Game Tips

- Look at the numbers on each piece
- Pieces will only fit in their correct positions
- Use the shuffle button if you can't find the piece you need
- Work systematically from one corner

## Technical Details

- Pure HTML5, CSS3, and Vanilla JavaScript
- No external dependencies or images
- Drag and drop API support
- Touch events for mobile
- Mobile-optimized with responsive design

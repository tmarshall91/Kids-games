# Drawing Pad 🎨

A fun and interactive drawing application for kids with multiple colors, brush sizes, and tools.

## How to Play

1. **Choose a Color**: Tap on any color from the palette
2. **Select Brush Size**: Choose from small to large brush sizes
3. **Start Drawing**: Use your finger (or mouse) to draw on the canvas
4. **Use Tools**:
   - 🖌️ Brush: Draw with colors
   - 🧹 Eraser: Remove parts of your drawing
   - 🗑️ Clear: Start fresh with a blank canvas

## Features

- **10 Vibrant Colors**: Red, Orange, Yellow, Green, Blue, Purple, Pink, Black, White, and Brown
- **4 Brush Sizes**: From tiny details to bold strokes
- **Smooth Drawing**: Responsive touch and mouse support
- **Eraser Tool**: Fix mistakes easily
- **Quick Clear**: Start over with one tap

## Technical Details

- Pure HTML5 Canvas API
- Touch-optimized for mobile devices
- Smooth line rendering with lineCap and lineJoin
- Responsive design that adapts to screen size
- No external dependencies

## Controls

- **Touch**: Drag your finger to draw
- **Mouse**: Click and drag to draw
- **Tap/Click**: Select colors, sizes, and tools

# Checkers

A simplified version of the classic board game. Capture all your opponent's pieces to win!

## How to Play

1. You are Red, the computer is White
2. Tap one of your pieces to select it
3. Valid moves will be highlighted in green
4. Tap a highlighted square to move
5. Jump over opponent pieces to capture them
6. Reach the opposite end to become a King (moves in all directions)
7. Capture all opponent pieces to win!

## Features

- Play against computer opponent
- Simplified rules perfect for kids
- Visual highlighting of valid moves
- King promotion with crown symbol
- Mobile-friendly touch controls
- Capture counter

## Technical Details

- Pure HTML5, CSS3, and Vanilla JavaScript
- 8×8 checkerboard
- AI opponent with capture priority
- Responsive design for all screen sizes
- Touch and mouse event support
- No external dependencies

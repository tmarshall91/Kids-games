# Kids Solitaire

A simplified, kid-friendly version of the classic Solitaire (Klondike) card game with colorful emoji cards and easy-to-understand rules!

## How to Play

### Objective
Move all 52 cards to the four foundation piles, building up from Ace to King in each suit.

### Game Setup
- 7 tableau piles with cards dealt face-down, with the top card face-up
- 4 foundation piles (one for each suit: ❤️ Hearts, 💎 Diamonds, ♣️ Clubs, ♠️ Spades)
- 1 stock pile with remaining cards
- 1 waste pile for drawn cards

### Rules (Simplified for Kids)

**Foundation Piles:**
- Each foundation pile is for one suit
- Build up from Ace (A) to King (K)
- Example: A → 2 → 3 → 4 → ... → Q → K

**Tableau Piles:**
- Build down by rank, alternating colors (red/black)
- Example: Red 7 → Black 6 → Red 5 → Black 4
- Any card can be moved to an empty tableau pile (simplified rule!)
- You can move multiple cards together if they're properly stacked

**Stock and Waste:**
- Tap the stock pile to draw one card to the waste pile
- The top card of the waste pile can be moved to tableau or foundation
- When stock is empty, tap to reset it from waste

**Controls:**
- Tap a card to select it (it will lift up with a golden glow)
- Tap where you want to move it
- Tap the deck to draw new cards
- Use the 💡 Hint button if you're stuck!

### Winning
Complete all four foundation piles with all 13 cards in each suit!

### Kid-Friendly Simplifications
Unlike traditional Klondike Solitaire, this version includes:
1. **Any card to empty tableau**: Kids can move any card (not just Kings) to empty tableau piles
2. **Visual hints**: The hint button provides helpful suggestions
3. **Clear visual feedback**: Selected cards glow gold, valid moves are obvious
4. **Emoji cards**: Large, colorful emoji suit symbols instead of traditional card designs
5. **Encouraging messages**: Positive feedback for good moves

## Tips for Kids

1. **Start with foundation moves**: Always try to move Aces and low cards to foundation piles first
2. **Expose hidden cards**: Focus on flipping face-down cards in the tableau
3. **Plan ahead**: Think about what cards you need to uncover
4. **Use hints**: Don't be afraid to use the hint button when stuck
5. **Empty piles are useful**: Use empty tableau piles to reorganize cards
6. **Be patient**: Not every game can be won - that's okay! Just restart and try again

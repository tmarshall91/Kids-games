# Cookie Clicker

A fun, addictive incremental clicker game where you click cookies to earn points and buy upgrades that automatically generate cookies for you!

## How to Play

1. **Click the Cookie**: Tap or click the big cookie in the center to earn cookies
2. **Buy Upgrades**: Spend your cookies in the shop to buy automatic cookie generators
3. **Earn More**: Each upgrade generates cookies automatically every second
4. **Keep Growing**: The more you buy, the faster you earn cookies!
5. **Progress Saves**: Your game automatically saves, so you can come back anytime

### Controls

- **Tap/Click Cookie**: Earn 1 cookie per click
- **Tap Upgrades**: Purchase upgrades to automate cookie production
- **Info Button (ℹ️)**: View instructions again
- **Reset Button**: Start over from scratch

## Features

- **Idle/Incremental Gameplay**: Earn cookies even when the game is running in the background
- **7 Different Upgrades**: From cursors to time machines, each with unique cookie generation rates
- **Progressive Difficulty**: Upgrade costs increase with each purchase
- **Offline Earnings**: Earn cookies while you're away (up to 1 hour)
- **Auto-Save**: Game progress saves automatically every 5 seconds
- **Mobile Optimized**: Touch-friendly controls designed for mobile devices
- **Responsive Design**: Works great on phones, tablets, and desktop
- **Visual Feedback**: See your clicks with animated +1 numbers
- **Number Formatting**: Large numbers display as K, M, B, T for readability

## Game Design Notes

This game follows the classic "Cookie Clicker" formula, an incremental game genre where:
- Player performs a simple action (clicking)
- Actions earn resources (cookies)
- Resources buy upgrades that automate the action
- Automation allows for exponential growth
- Creates a satisfying progression loop

The game is balanced for kids with:
- Simple, clear visuals
- Easy-to-understand mechanics
- Positive feedback for all actions
- No failure states or punishment
- Bright, colorful design
- Fun emoji icons

## Tips for Players

1. **Start Small**: Focus on cheaper upgrades first to build up your cookie production
2. **Balance Your Portfolio**: Buy multiple types of upgrades instead of just one
3. **Check Back Often**: The game continues earning while you're away (up to 1 hour)
4. **Save Before Closing**: The game auto-saves, but you can close the info panel to trigger a save
5. **Exponential Growth**: Later upgrades cost more but generate way more cookies!

# Stamp Art ✨

Create beautiful art by placing colorful emoji stamps and stickers on your canvas!

## How to Play

1. **Choose a Stamp**: Select your favorite emoji from the collection
2. **Pick a Size**: Choose small, medium, or large
3. **Place Stamps**: Tap anywhere on the canvas to place stamps
4. **Create Art**: Build scenes, patterns, or anything you imagine!

## Features

- **20 Fun Stamps**: Smiley faces, animals, flowers, stars, hearts, and more
- **3 Size Options**: Small, medium, and large stamps
- **Unlimited Placement**: Place as many stamps as you want
- **Easy Clear**: Start fresh anytime
- **Touch Optimized**: Perfect for little fingers

## Stamp Categories

- **Faces**: Happy, laughing, cool, and party faces
- **Animals**: Dogs, cats, lions, pandas, and butterflies
- **Nature**: Flowers, rainbows, and stars
- **Hearts**: Various heart styles
- **Fun**: Art palettes, theater masks, circus tents

## Technical Details

- HTML5 Canvas for rendering
- Emoji-based stamps (no image assets needed)
- Touch and mouse support
- Responsive design
- Efficient rendering system

## Controls

- **Tap/Click Canvas**: Place selected stamp
- **Tap Emoji**: Select that stamp
- **Tap Size**: Change stamp size
- **Clear All**: Remove all stamps

# Word Search

Find hidden words in a grid of letters! Drag across letters to select words horizontally, vertically, or diagonally.

## How to Play

1. Tap "Start Game" to begin
2. Look at the word list at the top
3. Find each word in the grid
4. Drag your finger (or mouse) across letters to select a word
5. Words can be horizontal, vertical, or diagonal
6. Find all words as quickly as you can!

## Features

- Touch-optimized drag selection
- Timer to track your speed
- Hint system to help find words
- Randomly generated grids each game
- Kid-friendly words (animals)
- Responsive design for all screen sizes

## Technical Details

- Pure HTML5, CSS3, and Vanilla JavaScript
- Mobile-first design
- Touch and mouse support
- No external dependencies
- Works offline

## Controls

- **Touch**: Drag across letters to select
- **Mouse**: Click and drag across letters
- **Hint Button**: Highlights the next word to find

## Words

Current word list includes: CAT, DOG, BIRD, FISH, BEAR

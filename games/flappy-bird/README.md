# Flappy Bird

A mobile-friendly clone of the classic Flappy Bird game. Tap to keep the bird flying and avoid the pipes!

## How to Play

1. Tap the "Start Game" button to begin
2. Tap anywhere on the screen to make the bird flap and fly upward
3. Navigate through the gaps between pipes
4. Score points by passing through pipes
5. Avoid hitting the pipes or the ground
6. Try to beat your high score!

## Features

- Smooth 60 FPS gameplay
- Touch-optimized controls
- Score tracking with high score persistence
- Responsive design for all mobile devices
- Simple one-tap controls
- Progressive difficulty

## Technical Details

- **Technologies**: HTML5 Canvas, CSS3, Vanilla JavaScript
- **Browser Requirements**: Modern mobile browsers (iOS Safari 12+, Chrome 80+)
- **Controls**: Touch/Click
- **Storage**: Uses localStorage for high score persistence

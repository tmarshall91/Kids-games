# Color Learning

Learn colors through interactive matching! Kids can identify and match different colors by name.

## How to Play

1. Tap "Start Learning!" to begin
2. Read the color name shown
3. Tap the correct color from the options
4. Learn from feedback and continue!

## Features

- 10 different colors to learn
- Visual color swatches
- Multiple choice format
- Immediate feedback
- Score tracking
- Bright, engaging design

## Colors Included

- Red
- Blue
- Green
- Yellow
- Orange
- Purple
- Pink
- Brown

## Educational Value

Helps children:
- Recognize colors
- Learn color names
- Develop visual discrimination
- Build vocabulary
- Practice decision making

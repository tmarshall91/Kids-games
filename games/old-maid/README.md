# Old Maid

A classic card elimination game where players try to avoid being left with the Old Maid card.

## How to Play

1. Each player starts with half the deck
2. Pairs (same rank and color) are automatically removed
3. Take turns drawing cards from each other's hand
4. If you make a pair, it's automatically discarded
5. The player left with the Old Maid loses!

## Features

- Mobile-friendly touch controls
- Automatic pair detection and removal
- Visual feedback for the Old Maid card
- Turn-based gameplay
- Simple and intuitive interface

## Technical Details

- Pure HTML5, CSS3, and Vanilla JavaScript
- Responsive design for all screen sizes
- Touch and mouse event support
- No external dependencies

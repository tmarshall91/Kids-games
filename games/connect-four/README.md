# Connect Four

Drop your colored tokens and try to connect four in a row before the computer does!

## How to Play

1. You are Red, the computer is Yellow
2. Tap any column to drop your token
3. Tokens fall to the lowest available space
4. Connect four tokens in a row (horizontal, vertical, or diagonal) to win!
5. Block the computer from connecting four

## Features

- Play against a smart computer opponent
- Animated token drops
- Winning combinations highlighted
- Mobile-friendly touch controls
- Classic Connect Four gameplay

## Technical Details

- Pure HTML5, CSS3, and Vanilla JavaScript
- AI opponent with strategic moves
- 7×6 game board
- Responsive design for all screen sizes
- Touch and mouse event support
- No external dependencies

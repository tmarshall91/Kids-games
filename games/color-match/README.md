# Color Match 🎨

A fast-paced color matching game for kids! Test your color recognition skills by tapping the correct color as quickly as you can. Race against the clock and see how many colors you can match in 30 seconds!

## 🎮 How to Play

1. **Start the Game**: Tap the "Start Game" button
2. **Read the Color Name**: A color name will appear at the top (e.g., "RED")
3. **Tap the Matching Color**: Choose the button that matches the color name shown
4. **Score Points**: Get 10 points for each correct answer
5. **Beat the Clock**: You have 30 seconds to match as many colors as possible!

## 🎯 Game Features

- **10 Vibrant Colors**: Red, Blue, Green, Yellow, Orange, Purple, Pink, Brown, Black, and Gray
- **4 Options Per Round**: Multiple choice makes it fun and accessible
- **Visual Feedback**: Buttons animate when you tap them
- **Score Tracking**: See your score increase with each correct answer
- **Accuracy Stats**: View your accuracy percentage at the end
- **Mobile Optimized**: Large, touch-friendly buttons perfect for kids
- **Colorful Design**: Bright, engaging colors and smooth animations

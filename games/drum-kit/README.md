# Drum Kit

An interactive virtual drum set where kids can play percussion instruments and record their beats!

## How to Play

1. Tap any drum or cymbal to play its sound
2. Experiment with different combinations to create rhythms
3. Use the "Record" button to start recording your beat
4. Play your drums while recording
5. Tap "Stop Recording" when finished
6. Press "Play Recording" to hear your beat played back

## Instruments

**Cymbals (Top Row):**
- Crash Cymbal (left) - Loud crashing sound
- Ride Cymbal (right) - Shimmering sustained sound

**Toms (Middle Row):**
- High Tom (left) - High pitched drum
- Mid Tom (center) - Medium pitched drum
- Low Tom (right) - Deep bass drum sound

**Main Drums (Bottom Row):**
- Snare Drum (left) - Sharp snare sound
- Bass Drum (center) - Deep kick drum
- Hi-Hat (right) - Crisp cymbal chick sound

## Features

- **8 Different Percussion Sounds**: Each instrument has a unique synthesized sound
- **Recording Feature**: Record your drum patterns and play them back
- **Visual Feedback**: Drums animate when hit
- **Touch Optimized**: Perfect for mobile touch screens
- **No External Audio**: All sounds generated using Web Audio API
- **Unlimited Creativity**: Create any rhythm pattern you can imagine

## Game Mechanics

- Tap any drum to hear its sound instantly
- Record button captures timing and sequence of drum hits
- Playback recreates your exact performance with timing
- Visual animations show which drums are being played

## Technical Details

- **Technologies**: HTML5, CSS3, Vanilla JavaScript, Web Audio API
- **Mobile Optimized**: Touch-friendly responsive design
- **Browser Requirements**: Modern browsers with Web Audio API support
- **No Dependencies**: Pure web technologies, synthesized audio
- **Self-Contained**: No external audio files needed

## Learning Benefits

- **Rhythm Development**: Practice timing and rhythm patterns
- **Musical Creativity**: Express yourself through percussion
- **Coordination**: Develop hand-eye coordination
- **Pattern Recognition**: Create and remember beat patterns
- **Introduction to Music**: Learn about different percussion instruments

## Tips

- Try playing simple patterns like "boom-tap-boom-tap" (bass-snare-bass-snare)
- Experiment with hi-hat patterns
- Record short loops and listen to how they sound
- Practice keeping a steady rhythm

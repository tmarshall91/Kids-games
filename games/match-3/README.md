# 🍬 Sweet Match 3

A colorful and fun Match-3 puzzle game inspired by Candy Crush! Match colorful sweets to score points and complete levels.

## How to Play

1. **Tap Start** to begin the game
2. **Tap a candy** to select it
3. **Tap an adjacent candy** to swap them
4. **Match 3 or more** of the same candy to score points
5. **Reach the target score** before running out of moves!

## Controls

- **Tap/Click**: Select and swap candies
- **Adjacent Swaps Only**: You can only swap candies that are next to each other (horizontally or vertically)

## Candy Types

The game features 6 different colorful sweets:
- 🍬 Hard Candy
- 🍭 Lollipop
- 🍫 Chocolate
- 🍩 Donut
- 🍪 Cookie
- 🧁 Cupcake

## Scoring

- **Base Points**: 10 points per candy matched
- **Combos**: Chain reactions multiply your score!
- **Longer Matches**: Match more than 3 for bonus points
- **Target Score**: Reach 1000 points to win

## Game Objective

- Match 3 or more candies of the same type
- Create combos by triggering chain reactions
- Reach the target score within 20 moves
- Get 3 stars for excellent performance!

## Features

- 8x8 colorful game board
- 6 different candy types
- Combo system with multipliers
- Chain reaction mechanics
- Smooth animations and transitions

## Tips & Tricks

- Look for potential chain reactions
- Plan your moves to create combos
- Match from the bottom to create cascades
- Try to match 4 or 5 candies for special effects
- Don't rush - think about each move!

## Difficulty Levels

- **Target Score**: 1000 points
- **Moves Available**: 20 moves
- **⭐ 1 Star**: Complete the level
- **⭐⭐ 2 Stars**: Score 1000+ points
- **⭐⭐⭐ 3 Stars**: Score 1500+ points

# Pattern Designer 🎭

Create beautiful symmetrical patterns and mandalas with automatic mirroring!

## How to Play

1. **Choose Symmetry**: Select 2-way, 4-way, 6-way, or 8-way patterns
2. **Pick a Color**: Choose from vibrant colors
3. **Draw**: Your strokes are automatically mirrored to create patterns
4. **Create Art**: Build intricate mandalas and symmetrical designs

## Features

- **4 Symmetry Modes**: 2-way mirror, 4-way, 6-way, 8-way mandala
- **6 Colors**: Bright, kid-friendly palette
- **Real-time Mirroring**: See patterns form as you draw
- **Guide Lines**: Subtle center guides help with composition
- **Smooth Drawing**: Responsive touch rendering

## Technical Details

- HTML5 Canvas with rotation algorithms
- Mathematical symmetry calculations
- Touch-optimized drawing
- Real-time pattern generation

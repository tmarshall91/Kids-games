# Dot-to-Dot Generator 🔢

Connect numbered dots in sequence to reveal beautiful shapes and patterns!

## How to Play

1. **Start the Game**: A pattern of numbered dots appears
2. **Connect in Order**: Tap dots in numerical order (1, 2, 3...)
3. **Watch the Picture Form**: Lines connect as you tap correctly
4. **Complete the Picture**: Connect all dots to finish!

## Features

- **Multiple Shapes**: Circles, stars, hearts, and spirals
- **Three Difficulty Levels**:
  - Easy: 10 dots
  - Medium: 20 dots
  - Hard: 30 dots
- **Hint System**: Get help finding the next dot
- **Progress Tracking**: See how many dots you've connected
- **Success Animation**: Celebration when you complete a picture
- **Random Generation**: Each game creates a new unique pattern

## Technical Details

- HTML5 Canvas for smooth rendering
- Touch and mouse support
- Multiple shape algorithms (circle, star, heart, spiral)
- Dynamic difficulty scaling
- Responsive design for all screen sizes

## Controls

- **Tap/Click**: Connect dots in order
- **New Picture**: Generate a fresh puzzle
- **Show Hint**: Highlights the next dot to connect
- **Difficulty Selector**: Choose your challenge level

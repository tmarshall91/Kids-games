# Karaoke Sing-Along

Sing along with popular children's songs! Perfect for practicing singing and learning song lyrics.

## How to Play

1. Select a song using the arrow buttons
2. Press "Play" to start the karaoke
3. Sing along as the lyrics appear on screen
4. The current line to sing is shown in large text
5. The next line is shown below in smaller text
6. Use "Pause" to stop and "Restart" to begin again

## Available Songs

1. **Twinkle Twinkle Little Star** - Classic lullaby
2. **Mary Had a Little Lamb** - Traditional nursery rhyme
3. **Row Row Row Your Boat** - Fun action song
4. **The Wheels on the Bus** - Popular children's song
5. **Old MacDonald Had a Farm** - Farm animal song

- Lyrics change automatically at song pace

- Microphone icon pulses when song is playing

## Singing Tips

- Read the next line while singing the current line
- Watch the progress bar to pace yourself
- Practice with pause/restart until you know the song
- Sing loudly and clearly
- Have fun - there's no wrong way to sing!

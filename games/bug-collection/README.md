# Bug Collection Game 🐛🦋

Catch and collect all 10 different types of bugs in this fun insect collecting adventure!

## How to Play

1. Tap **Start Collecting** to begin your bug hunt
2. Bugs will appear randomly in the garden
3. Quickly tap each bug to catch and add it to your collection
4. Bugs disappear after a few seconds if not caught
5. Try to collect all 10 different bug types!

## Features

- **10 different bugs** to collect: Caterpillar, Butterfly, Bee, Ladybug, Cricket, Spider, Mosquito, Beetle, Fly, Scorpion
- **Collection tracker** showing caught vs total types
- **View Collection** button to see your progress
- **Beautiful garden scenery** with flowers and grass
- **Animated bugs** that move naturally
- Score counter tracking total catches
- Complete celebration when all types are collected

## Game Mechanics

- Multiple bugs can appear at once (max 4)
- Each bug stays for about 3.5 seconds
- New bugs spawn every 1.5 seconds
- Catch multiple of the same type to increase count
- Game completes when all 10 types are caught at least once

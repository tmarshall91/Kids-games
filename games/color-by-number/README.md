# Color by Number

Tap regions to fill them with matching colors and create beautiful artwork!

## How to Play

1. Click "Start Coloring" to begin
2. Select a color from the palette at the top
3. Tap on regions with the matching number
4. Fill all regions to complete the picture!

## Controls

- **Tap Color Button**: Select a color to use
- **Tap Region**: Fill a region with the selected color
- **Clear All**: Remove all colors and start over
- **New Picture**: Get a different picture to color

## Features

- Color palette with 6 vibrant colors
- Multiple picture templates
- Number labels in uncolored regions
- Progress tracker shows percentage complete
- Final artwork reveal
- Touch-friendly for mobile
- Regions only fill with correct color number
- Smooth canvas rendering

## Game Tips

- Select a color first, then tap matching numbered regions
- The active color button has a highlighted border
- Work systematically through one color at a time
- Watch your progress percentage increase!

## Technical Details

- Pure HTML5, CSS3, and Vanilla JavaScript
- HTML5 Canvas for drawing
- Point-in-polygon detection for region clicks
- No external dependencies
- Touch and mouse support
- Mobile-optimized with responsive sizing

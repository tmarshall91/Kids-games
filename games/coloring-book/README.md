# Coloring Book 🎨

Fill beautiful outlined pictures with your favorite colors!

## How to Play

1. **Choose a Picture**: Select from flower, star, heart, sun, or butterfly
2. **Pick a Color**: Tap a color from the palette
3. **Color**: Tap or drag to fill the picture with color
4. **Reset**: Start fresh with the same picture anytime

## Features

- **5 Pictures**: Flower, star, heart, sun, and butterfly outlines
- **8 Colors**: Vibrant color palette
- **Free Coloring**: Color anywhere on the canvas
- **Instant Reset**: Try different color combinations
- **Smooth Coloring**: Touch-responsive brush

## Technical Details

- HTML5 Canvas with procedural drawing
- Mathematical shape generation
- Touch and mouse support
- Brush-based coloring system

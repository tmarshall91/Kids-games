# Crossy Road

Navigate through traffic and rivers in this endless crossing game!

## How to Play

1. Tap "Start Crossing" to begin
2. Use arrow buttons to move up, down, left, or right
3. **Grass**: Safe zones
4. **Roads**: Avoid moving cars
5. **Rivers**: Jump on logs to cross (you'll move with the log!)
6. Move forward to score points
7. Don't get hit by cars or fall in the water!

## Features

- Three terrain types: grass, roads, and rivers
- Moving obstacles (cars and logs)
- Touch-friendly directional buttons
- Keyboard support (arrow keys)
- Endless procedurally generated levels
- Score tracking with high score persistence

## Technical Details

- **Technologies**: HTML5 Canvas, CSS3, Vanilla JavaScript
- **Browser Requirements**: Modern mobile browsers (iOS Safari 12+, Chrome 80+)
- **Controls**: Touch buttons or arrow keys
- **Storage**: Uses localStorage for high score persistence

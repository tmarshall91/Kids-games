# Balloon Pop 🎈

A fun, colorful balloon popping game for kids! Tap the floating balloons before they drift away!

## 🎮 How to Play

1. Tap **Start Game** to begin
2. Tap the balloons as they float up from the bottom of the screen
3. Pop as many balloons as you can before time runs out!
4. Bigger balloons are worth more points

## 🎯 Game Rules

- **Game Duration**: 30 seconds
- **Scoring**:
  - Small balloons: 5 points
  - Medium balloons: 10 points
  - Large balloons: 15 points

## 🎲 Game Mechanics

- Balloons spawn continuously from the bottom
- Each balloon floats upward at different speeds
- Larger balloons float slower (easier to pop, more points)
- Smaller balloons float faster (harder to pop, fewer points)
- Balloons drift slightly left or right as they float
- Balloons disappear if they reach the top unpoppedapk

## 🏆 Scoring System

The game tracks:
- Total score
- Number of balloons popped
- Number of balloons spawned
- Time remaining

At the end, you'll receive an encouraging message based on your performance!

## 🎨 Customization

You can easily customize:
- Game duration (CONFIG.gameTime)
- Balloon spawn rate (CONFIG.spawnInterval)
- Float speeds (CONFIG.floatDuration)
- Point values (CONFIG.points)
- Colors (CONFIG.balloonColors)
- Size distribution (CONFIG.sizeWeights)

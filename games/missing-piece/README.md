# Missing Piece

Compare two scenes and identify what's missing from the second one!

## How to Play

1. Click "Start Game" to begin
2. Look carefully at the complete scene (left/top)
3. Compare it to the incomplete scene (right/bottom)
4. Identify what's missing
5. Tap the correct answer from the choices below
6. Complete 10 rounds to finish the game!

## Controls

- **Tap/Click**: Select your answer
- **💡 Hint**: Briefly highlights the correct answer (10-second cooldown)

## Features

- 10 rounds per game
- Multiple themed scenes (farm, fruits, vehicles, ocean, weather, sports)
- 4-5 items per scene
- Score tracking (1 point per correct answer)
- Round counter
- Hint system with cooldown
- Instant visual feedback
- Colorful emoji-based items
- Touch-friendly interface

## Game Tips

- Compare both scenes carefully
- Count the items in each scene
- Look for what appears in the first but not the second
- Use hints wisely (they have a cooldown)
- Take your time - there's no rush!

## Technical Details

- Pure HTML5, CSS3, and Vanilla JavaScript

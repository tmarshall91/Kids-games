# Math Facts

Practice basic addition and subtraction with this fun, interactive math game for kids!

## How to Play

1. Choose your difficulty level:
   - Easy (numbers 1-5)
   - Medium (numbers 1-10)
   - Hard (numbers 1-20)
2. Solve the math problem shown on screen
3. Tap the correct answer from the choices
4. Build your score and streak!
5. Switch between addition and subtraction anytime

## Features

- Three difficulty levels
- Both addition and subtraction practice
- Multiple choice answers (6 options)
- Score tracking
- Streak counter for consecutive correct answers
- Immediate feedback on answers
- Colorful, engaging interface
- Progressive learning support

## Educational Value

This game helps children:
- Master basic addition facts
- Practice subtraction skills
- Build mental math abilities
- Develop number sense
- Improve calculation speed
- Build confidence with math

## Technical Details

- Pure HTML5, CSS3, and vanilla JavaScript
- Touch-optimized buttons
- Responsive design
- No external dependencies
- Works offline
- Mobile-first approach

## Game Modes

### Addition Mode (Default)
- Add two numbers together
- Positive numbers only
- Get immediate feedback

### Subtraction Mode
- Subtract smaller number from larger
- Results are always positive (kid-friendly)
- Practice inverse operations

## Difficulty Levels

- **Easy (1-5)**: Perfect for beginners, small numbers
- **Medium (1-10)**: Standard elementary practice
- **Hard (1-20)**: Challenge mode for advanced learners

## Controls

- **Touch/Click**: Select answer buttons
- **Difficulty Buttons**: Choose your challenge level
- **Operation Buttons**: Switch between + and −
- **Back to Menu**: Choose a different difficulty

## Scoring

- +10 points for each correct answer
- Streak counter shows consecutive correct answers
- No penalties for wrong answers (encourages learning)

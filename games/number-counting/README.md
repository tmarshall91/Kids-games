# Number Counting

An interactive counting game that helps kids learn numbers by counting colorful objects on screen.

## How to Play

1. Tap "Start Game" to begin
2. Count the objects that appear on screen
3. Tap the correct number from the answer choices
4. Get points for correct answers!
5. The game gets progressively harder with more objects to count

## Features

- Colorful emoji objects to count
- Multiple choice answers (6 options)
- Progressive difficulty (starts easy, gets harder)
- Immediate visual feedback
- Score and level tracking
- Animated objects that pop in
- Kid-friendly interface

## Educational Value

This game helps children:
- Learn number recognition (1-10)
- Practice counting skills
- Develop one-to-one correspondence
- Build number sense
- Improve visual discrimination

## Technical Details

- Pure HTML5, CSS3, and vanilla JavaScript
- Touch-optimized button interface
- Emoji-based objects (no images needed)
- No external dependencies
- Works offline
- Mobile-first responsive design

## Controls

- **Touch/Click**: Select your answer from the number buttons
- **Start Game**: Begin playing
- **Continue**: Move to next question

## Difficulty

- Beginner-friendly (starts with 1-3 objects)
- Progressive difficulty (adds more objects as you level up)
- Maximum of 10 objects to count
- Wrong answers show the correct answer

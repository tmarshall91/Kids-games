# Doodle Jump

A fun vertical platformer where you bounce upward on platforms! How high can you go?

## How to Play

1. Tap "Start Jumping" to begin
2. **Tap left side** of screen to move left
3. **Tap right side** of screen to move right
4. Land on platforms to bounce higher
5. The character automatically bounces when landing on platforms
6. Don't fall off the bottom of the screen!
7. Try to reach the highest score possible!

## Features

- Endless vertical scrolling
- Simple tap controls for left/right movement
- Automatic bouncing on platforms
- Platform generation as you climb
- Score based on height achieved
- High score tracking
- Smooth physics and animations
- Responsive mobile design

## Technical Details

- **Technologies**: HTML5 Canvas, CSS3, Vanilla JavaScript
- **Browser Requirements**: Modern mobile browsers (iOS Safari 12+, Chrome 80+)
- **Controls**: Touch/Click (left side = move left, right side = move right)
- **Storage**: Uses localStorage for high score persistence

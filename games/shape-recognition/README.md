# Shape Recognition

Learn shapes through interactive matching! Kids can identify and match different geometric shapes.

## How to Play

1. Tap "Start Learning!" to begin
2. Read the shape name shown
3. Tap the correct shape from the options
4. Learn from feedback and continue!

## Features

- 6 different shapes: Circle, Square, Triangle, Rectangle, Star, Heart
- Visual shape representations using CSS
- Multiple choice format
- Immediate feedback
- Score tracking
- Colorful, engaging design

## Educational Value

Helps children:
- Recognize basic shapes
- Learn shape names
- Develop visual discrimination
- Build spatial awareness
- Practice decision making

## Shapes Included

- **Circle**: Round shape
- **Square**: Four equal sides
- **Triangle**: Three sides
- **Rectangle**: Four sides, opposite sides equal
- **Star**: Five-pointed star
- **Heart**: Classic heart shape

## Technical Details

- Pure HTML5, CSS3, and vanilla JavaScript
- Shapes created with pure CSS
- Touch-optimized interface
- No external dependencies
- Mobile-first responsive design

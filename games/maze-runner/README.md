# Maze Runner

Navigate through increasingly challenging mazes to reach the goal!

## How to Play

1. Click "Start Game" to begin
2. Guide the blue player 🔵 to the green goal 🎯
3. Use arrow keys or swipe to move
4. Avoid bumping into walls
5. Complete all levels to win!

## Controls

- **Arrow Keys**: Move up, down, left, right (desktop)
- **WASD**: Alternative keyboard controls
- **Swipe**: Move in any direction (mobile)
- **Restart Level**: Start the current maze over
- **New Game**: Return to level 1

## Features

- 3 progressively harder levels
- Swipe-based mobile controls
- Keyboard controls for desktop
- Move counter per level
- Visited path tracking (light blue)
- Can't move through walls
- Level progression system
- Responsive maze sizing

## Game Tips

- Plan your route before moving
- Watch out for dead ends
- Visited cells turn light blue
- Use the restart button if you get stuck
- The fewer moves, the better!

## Technical Details

- Pure HTML5, CSS3, and Vanilla JavaScript
- Grid-based maze rendering
- Touch swipe detection
- Keyboard event handling
- No external dependencies
- Mobile-optimized with touch controls
- Responsive grid sizing

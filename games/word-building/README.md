# Word Building

A fun and educational word-building game where kids combine letters to make words! Tap letters to build words and discover how many you can find.

## How to Play

1. **Start the Game**: Tap the "Start Game" button to begin
2. **Build Words**: Tap letters from the available letter tiles to build words
3. **Submit Words**: Once you have 3 or more letters, tap "Submit Word" to check if it's valid
4. **Find More Words**: Keep building and submitting words to increase your score
5. **Next Set**: After finding words in the current set, move to the next letter set
6. **Complete All Sets**: Play through all 5 letter sets to finish the game

### Controls

- **Tap letter tiles** to add them to your word
- **Tap letters in the word builder** to remove them
- **Submit Word** button to check if your word is valid
- **Clear** button to clear the current word and start over
- **Next Set** button to move to the next set of letters (appears after you've found at least one word)

## Game Rules

- Words must be at least **3 letters long**
- Each letter can only be used once per word
- Words must be valid English words from the game dictionary
- You can't submit the same word twice in one set
- Score is based on word length (3-letter word = 3 points, 4-letter word = 4 points, etc.)

## Educational Benefits

- **Vocabulary Building**: Learn new words and word patterns
- **Spelling Practice**: Improve spelling skills through word construction
- **Pattern Recognition**: Recognize common letter combinations
- **Critical Thinking**: Plan which letters to use for different words
- **Problem Solving**: Figure out multiple words from the same set of letters

## Tips for Success

- Start with simple 3-letter words to build confidence
- Look for common word patterns like "-at", "-and", "-ing"
- Try different letter combinations
- Common small words: cat, rat, bat, sat, can, ran, tan, etc.
- Remember you can reuse letters for different words (but not in the same word!)
- Don't give up - there are many words possible in each set!

## Scoring

- **3-letter word**: 3 points
- **4-letter word**: 4 points
- **5-letter word**: 5 points
- **Bonus**: Find as many words as possible to maximize your score!

### Performance Messages

- **20+ words**: "Outstanding! You're a word master!"
- **15-19 words**: "Excellent work! Keep it up!"
- **10-14 words**: "Good job! You're getting better!"
- **Under 10 words**: "Nice try! Practice makes perfect!"

# 🟦 Block Puzzle

A fun block-fitting puzzle game for kids! Drag Tetris-style pieces onto the board and clear lines to score points.

## How to Play

1. **Tap Start** to begin the game
2. **Drag blocks** from the bottom onto the 8×8 grid
3. **Fill complete rows or columns** to clear them
4. **Keep playing** until no more blocks can fit!

## Controls

### Desktop
- **Drag and Drop**: Click and drag blocks to the board
- **Drop**: Release mouse to place block

### Mobile
- **Touch and Drag**: Touch and drag blocks to the board
- **Drop**: Release touch to place block

## Game Rules

- Drag blocks from the available pieces area to the board
- Place blocks anywhere they fit on the grid
- **Complete a row**: Fill all 8 cells in a horizontal row
- **Complete a column**: Fill all 8 cells in a vertical column
- Completed lines disappear and you earn points
- Game ends when no available pieces can fit on the board

## Scoring System

- **Block Placement**: 10 points per block placed
- **Line Clear**: 100 points per completed line
- **Multiple Lines**: Clear multiple lines at once for combo points
- **Best Score**: Your highest score is saved automatically

## Block Shapes

The game features various Tetris-style pieces:
- **Single Block**: 1×1
- **Two Blocks**: 1×2, 2×1
- **Three Blocks**: 1×3, 3×1, L-shapes
- **Four Blocks**: 2×2 squares, T-shapes
- **Five Blocks**: Plus shapes, complex patterns

## Game Features

- 8×8 game grid
- Multiple block shapes

- Score tracking

## Strategy Tips

- Plan ahead - look at all available pieces
- Try to clear multiple lines at once
- Leave space for awkward shaped pieces
- Fill from the edges when possible
- Don't rush - there's no time limit
- Watch for opportunities to clear rows AND columns together
- Keep the board organized

## Visual Feedback

- **Preview Mode**: Shows where piece will be placed (blue outline)
- **Filled Cells**: Purple gradient blocks
- **Clearing Animation**: Yellow flash when lines clear
- **Disabled Pieces**: Grayed out when used

## Learning Benefits

Block Puzzle helps kids develop:
- **Spatial Reasoning**: Fitting shapes into spaces
- **Planning Ahead**: Thinking about future moves
- **Problem Solving**: Finding the best placement
- **Visual Perception**: Seeing how pieces fit together
- **Decision Making**: Choosing where to place blocks
- **Pattern Recognition**: Identifying clearing opportunities

## Differences from Tetris

This is NOT Tetris! Key differences:
- No falling blocks
- No time pressure
- You choose where to place each piece
- Clear both rows AND columns
- Multiple pieces available at once
- More strategic and puzzle-like

## Game Over Conditions

The game ends when:
- None of the available pieces can fit anywhere on the board
- The board is too full to place any piece

**Tip**: Try to keep the board as clear as possible by completing lines frequently!

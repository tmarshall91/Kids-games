# Clock Reading Practice

Learn to tell time with an interactive analog clock! Practice reading the clock and setting the time.

## How to Play

**Quiz Mode:**
1. Select "Quiz Mode"
2. Look at the clock
3. Tap the correct time from the options
4. Get points for correct answers!

**Practice Mode:**
1. Select "Practice Mode"
2. See the target time to set
3. Use the arrow buttons to adjust hours and minutes
4. Tap "Check Time" to see if you're correct!

## Features

- Interactive analog clock with moving hands
- Quiz mode to test time reading skills
- Practice mode to learn setting the clock
- Hour and minute hand animations
- Score tracking
- Times on the hour and quarter hours
- Immediate feedback

## Educational Value

Helps children:
- Learn to read analog clocks
- Understand hour and minute hands
- Practice telling time
- Develop time awareness
- Build confidence with clocks

## Time Intervals

- Hours: 1-12
- Minutes: :00, :15, :30, :45 (on the hour and quarter hours)

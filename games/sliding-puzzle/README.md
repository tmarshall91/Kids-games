# Sliding Picture Puzzle

A classic sliding tile puzzle game where players rearrange numbered tiles to put them in order.

## How to Play

1. Choose your difficulty level (3×3, 4×4, or 5×5 grid)
2. Tap tiles adjacent to the empty space to slide them
3. Rearrange all tiles in numerical order (1, 2, 3, etc.)
4. Complete the puzzle in as few moves as possible!

## Controls

- **Tap/Click**: Move a tile into the empty space (if adjacent)
- **Shuffle**: Scramble the puzzle for a new game
- **New Game**: Return to difficulty selection

## Features

- Three difficulty levels (3×3, 4×4, 5×5)
- Move counter
- Timer to track completion time
- Guaranteed solvable puzzles (uses valid move shuffling)
- Mobile-friendly touch controls
- Responsive design

## Technical Details

# Magic Paint ✨

Reveal hidden pictures by painting over the gray layer!

## How to Play

1. **Start Painting**: Drag your finger over the gray area
2. **Watch Progress**: See the progress bar fill up
3. **Reveal Picture**: Uncover at least 80% to win
4. **New Picture**: Generate a fresh hidden picture anytime

## Features

- **Random Pictures**: Each game generates different emoji patterns
- **Progress Tracking**: See how much you've revealed
- **Scratch-off Effect**: Realistic reveal mechanic
- **Auto-Complete**: Reveals all when you reach 80%
- **Instant Reveal**: Skip to see the hidden picture

## Technical Details

- Dual-canvas layering system
- Destination-out compositing for scratch effect
- Real-time pixel counting
- Touch-optimized painting
- Random emoji generation

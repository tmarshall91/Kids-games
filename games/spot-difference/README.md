# Spot the Difference

Find all the differences between two colorful pictures in this classic observation game!

## How to Play

1. Click "Start Game" to begin
2. Look at both pictures carefully
3. Tap on the differences you find in Picture 2
4. Find all 5 differences to win
5. Use hints if you get stuck (10-second cooldown)

## Controls

- **Tap/Click**: Mark a difference on Picture 2
- **Hint Button**: Highlights one unfound difference
- **New Game**: Start a fresh puzzle

## Features

- Randomly generated colorful scenes
- 5 differences to find per game
- Hint system with cooldown
- Timer to track completion
- Different types of differences (color, size, missing elements)
- Visual feedback when differences are found
- Mobile-friendly touch controls
- Responsive design

## Game Tips

- Look systematically at each part of the images
- Pay attention to colors, sizes, and shapes
- Use the hint button wisely
- Take your time - accuracy is more important than speed!

## Technical Details

- Pure HTML5, CSS3, and Vanilla JavaScript
- No external dependencies or images
- Procedurally generated scenes using CSS shapes
- Mobile-optimized with touch support
- Smooth animations

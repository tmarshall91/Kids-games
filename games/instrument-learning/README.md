# Instrument Learning 🎸

Learn about musical instruments! Discover different instruments, hear their sounds, and learn fun facts.

## How to Play

1. Tap **Start Learning** to begin
2. **Browse instruments** by category
3. **Tap an instrument** to hear its sound
4. **Read interesting facts** about each one
5. Take quizzes to test your knowledge!

## Controls

- **Tap/Click**: Select and play instruments
- **Swipe**: Browse categories

## Features

- **20+ Instruments**: From many categories
- **Sound Samples**: Hear how each sounds
- **Educational Facts**: Learn about instruments
- **Categories**: Strings, Brass, Woodwinds, Percussion
- **Interactive Quiz**: Test your knowledge

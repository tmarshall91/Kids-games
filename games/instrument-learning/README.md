# Instrument Learning

Learn to play three different musical instruments: Piano, Guitar, and Xylophone! Explore sounds and create your own melodies.

## How to Play

1. Select an instrument by tapping the tabs at the top
2. Tap keys, strings, or bars to play notes
3. Experiment with different notes and create melodies
4. Switch between instruments to hear different sounds
5. No rules - just explore and have fun!

## Instruments

### Piano
- 13 keys including white and black keys
- Full chromatic scale from C to C (octave)
- White keys: C, D, E, F, G, A, B, C
- Black keys: C#, D#, F#, G#, A#
- Sine wave synthesis for clean piano-like tones

### Guitar
- 6 strings representing a real guitar
- Standard tuning: E (low), A, D, G, B, E (high)
- Sawtooth wave synthesis for guitar-like tones
- Tap strings to hear open string notes

### Xylophone
- 8 colorful bars (C to C octave)
- Each bar is a different color
- Square wave synthesis for bright, bell-like tones
- Bars get shorter for higher notes (visual learning)

## Musical Concepts

**Piano Layout:**
- White keys are natural notes
- Black keys are sharps/flats
- Pattern repeats every octave

**Guitar Tuning:**
- Standard tuning is E-A-D-G-B-E
- Lower strings produce lower notes
- Real guitar layout

**Xylophone:**
- Shorter bars = higher notes
- Longer bars = lower notes
- Visual size matches pitch

## Playing Tips

**Piano:**
- Try playing simple melodies like "Mary Had a Little Lamb" (E-D-C-D-E-E-E)
- Experiment with black keys for different sounds

**Guitar:**
- Strings get higher from top to bottom
- Try playing all strings in order

**Xylophone:**
- Play from left to right for ascending scale
- Try playing random bars for fun sounds

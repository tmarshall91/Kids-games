# Sound Matching Game 🔊

A musical memory game! Listen to sounds and find matching pairs of musical instruments.

## How to Play

1. Tap **Start Game** to begin
2. **Tap any card** to reveal its sound and instrument
3. **Listen carefully** to each sound
4. **Find matching pairs** by tapping two cards with the same sound
5. Match all pairs to win!

## Controls

- **Tap/Click**: Flip cards to hear sounds

## Objective

- Match all 6 pairs of instrument sounds
- Remember what you've heard
- Complete the game as quickly as possible
- Earn 100 points for each match!

## Features

- **6 Different Instruments**: Guitar, Piano, Drum, Trumpet, Violin, Saxophone
- **Audio Feedback**: Each instrument has a unique sound
- **Memory Challenge**: Remember card positions
- **Score Tracking**: Earn points for matches
- **Time Tracking**: See how fast you can complete it

## Instruments

1. 🎸 **Guitar** - 330 Hz
2. 🎹 **Piano** - 440 Hz
3. 🥁 **Drum** - 200 Hz
4. 🎺 **Trumpet** - 550 Hz
5. 🎻 **Violin** - 660 Hz
6. 🎷 **Saxophone** - 370 Hz

## Game Mechanics

- **Card Flipping**: Tap to reveal and hear
- **Matching**: Two cards with same instrument match
- **Mismatch**: Cards flip back if not matching
- **Matched Pairs**: Stay visible when matched
- **Completion**: All pairs matched = victory!

## Scoring

- **Each Match**: 100 points
- **Total Possible**: 600 points
- **Time Bonus**: Faster completion = bragging rights!

- **Listen carefully** to each sound
- **Start systematically** - work through rows

- Remember the frequency/pitch of each sound

# Pet Dress-Up 🐕🐈

A fun and creative game where kids can customize their pet with different accessories, hats, and colorful backgrounds!

## How to Play

1. **Choose your pet** from 8 different animals
2. **Pick a hat** to put on your pet (or leave it without one)
3. **Add an accessory** like a bow, bone, or flower
4. **Select a background** to set the scene
5. Tap **Random!** for a surprise combination
6. Tap **Clear All** to start fresh

## Features

- **8 adorable pets**: Dog, Cat, Rabbit, Hamster, Bear, Fox, Panda, Koala
- **6 stylish hats**: Crown, Top Hat, Cap, Sun Hat, Bow, Star
- **6 cute accessories**: Bow, Diamond, Flower, Bone, Paw Print, Heart
- **6 colorful backgrounds**: Rainbow, Floral, Ocean, Starry, Pink, Sky
- Smooth animations and visual feedback
- Random outfit generator for instant fun
- Mobile-optimized touch controls

## Game Mechanics

- Mix and match any combination of items
- Each selection updates the pet instantly
- No wrong choices - pure creative fun!
- "None" option available for hats, accessories, and backgrounds
